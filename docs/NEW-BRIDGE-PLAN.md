# الجسر الجديد المستقل — Smart Manager

هذه الحزمة مستقلة بالكامل ولا تستورد أو تنسخ أي ملف من مشروع Online4Tech-Manager القديم.

## المرحلة الحالية
- تطبيق محلي على Windows باستخدام Python القياسي فقط.
- استماع على 127.0.0.1 حصريًا.
- فحص صحة الخدمة عبر /health.
- اقتران لمرة واحدة، جلسة عشوائية، والتحقق من CSRF.
- تقييد Origin وHost وحجم الطلبات ومعدل محاولات الاقتران.
- لا يوجد SSH أو تنفيذ أوامر أو كتابة ملفات أو نسخ احتياطي.

## التسليم
GitHub Actions يبني ملف ZIP واحدًا باسم Online4Tech-Smart-Manager-Bridge.zip كمرفق Artifact لمدة 30 يومًا.

## ما قبل ربط الرسيفر
يجب إضافة تكامل قراءة فقط مستقل ومراجع، مع مصادقة آمنة وتأكيد اختبار محلي. لا تعرض الواجهة حالة اتصال حقيقية قبل نجاح اختبار فعلي.
