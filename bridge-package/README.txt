ONLINE4TECH SMART MANAGER — LOCAL BRIDGE

التشغيل:
1) فك ضغط الملف ZIP بالكامل في مجلد عادي.
2) تأكد من وجود Python 3.10 أو أحدث.
3) اضغط مرتين على start.bat.
4) سيظهر كود اقتران لمرة واحدة في النافذة السوداء.
5) افتح Smart Manager ثم استخدم شاشة الاقتران عند توفرها، وأدخل الكود الظاهر.
6) اترك نافذة الجسر مفتوحة أثناء الاستخدام.

اختبار التشغيل:
افتح http://127.0.0.1:8765/health في المتصفح. يجب أن يظهر JSON وفيه ok:true.

الأمان والحالة:
- يستمع الجسر على 127.0.0.1 فقط ولا يفتح منفذًا على الشبكة.
- يسمح بطلبات الويب من نطاق Smart Manager الرسمي فقط.
- كود الاقتران لمرة واحدة، مع رمز جلسة ورمز CSRF.
- حد لحجم الطلبات ومحاولات الاقتران.
- هذه حزمة تأسيسية: الاقتران المحلي وفحص الحالة فقط.
- لا يوجد اتصال SSH بالرسيفر أو تنفيذ أوامر أو تعديل ملفات أو نسخ احتياطي.
- لا تدخل كلمة مرور الرسيفر في هذه النسخة.

المتطلبات: Windows 10/11 وPython 3.10+، ولا تحتاج مكتبات خارجية.
