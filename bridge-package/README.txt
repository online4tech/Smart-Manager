ONLINE4TECH SMART MANAGER — LOCAL BRIDGE 1.1.0

التشغيل:
1) فك ضغط ZIP بالكامل في مجلد عادي.
2) تأكد من وجود Python 3.10 أو أحدث.
3) اضغط مرتين على start.bat واترك النافذة مفتوحة.
4) افتح Smart Manager على نفس الكمبيوتر وأدخل كود الاقتران الظاهر.
5) بعد الاقتران، أدخل عنوان IPv4 الخاص بالرسيفر داخل شبكتك واضغط اختبار اتصال قراءة فقط.

المتطلبات على الرسيفر:
- تشغيل OpenWebif / Web Interface.
- الوصول إلى HTTP على المنفذ 80 أو HTTPS على 443.
- هذا الإصدار لا يرسل اسم مستخدم أو كلمة مرور؛ إذا كانت الواجهة محمية بتسجيل دخول فلن يتجاوز الحماية.

نطاق القراءة:
- يقرأ فقط /web/deviceinfo و /web/about بصيغة XML.
- يعرض اسم/موديل الجهاز وصورة النظام وإصدار Enigma2 إذا كانت متاحة.
- لا يقرأ قائمة القنوات أو البلجنات أو كلمات المرور أو ملفات الإعدادات.
- لا يوجد SSH أو shell أو تنفيذ أوامر أو كتابة أو حذف أو تثبيت أو نسخ احتياطي.
- لا يحفظ عنوان IP أو بيانات الرسيفر على القرص؛ الحالة في ذاكرة الجسر فقط.

الأمان:
- الجسر يستمع على 127.0.0.1 فقط.
- يقبل عناوين IPv4 الخاصة داخل الشبكة المحلية فقط، ويرفض إعادة التوجيه.
- يسمح بالمنفذين 80 و443 فقط، مع التحقق من شهادة HTTPS.
- لا يرسل بيانات اعتماد ولا يسجل كود الاقتران أو رموز الجلسة.
- كود الاقتران لمرة واحدة مع جلسة ورمز CSRF.

اختبار التشغيل: http://127.0.0.1:8765/health
المتطلبات: Windows 10/11 وPython 3.10+، دون مكتبات خارجية.
